# Geography Study Lab

A focused Grade 3 geography study site built from the supplied 60-question Bayou Bridges and world-geography quiz. The primary learner is the owner's son preparing for school tests; the site is public so anyone can use the same study set.

Target site: `https://aahplexx.github.io/geography/`

## Current state

The repository is in the approved design/specification phase. Product code has not been scaffolded yet.
