Existing GEO-001 routes and behavior remain the deployed baseline and must remain preserved.

## Approved architecture

- Additive real page at `/geography/explore/`; preserve `/geography/`, `/geography/exam/`, and `/geography/map/`.
- Local-first static geographic data built from pinned/validated Natural Earth layers.
- Optional World Bank and Wikimedia enrichment only; no login, payment, API key, or secret required.
- Normalized geography model spanning continents, countries/territories, global Admin-1 subdivisions, marine/water features, rivers/lakes, landforms/physical regions, and populated places represented by canonical datasets.
- Progressive/lazy geographic layer loading; no all-world-detail startup payload.
- Touch, mouse, wheel/trackpad, and keyboard interaction parity.
- Search, hierarchy/breadcrumbs, related exploration, compare, distance measurement, local bookmarks, recent exploration, deep links, and adaptive entity details.
- Phone bottom-sheet, tablet adaptive split/sheet, and desktop persistent-panel patterns.
- WCAG 2.2 AA target, reduced-motion support, visible focus, non-gesture equivalents, and explicit manual input QA.
