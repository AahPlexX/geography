## Architecture invariants

- Preserve every GEO-001 route/behavior; `/map/` and `/explore/` remain distinct.
- Local Natural Earth-derived data is authoritative; required behavior cannot depend on paid/signup/keyed services.
- Optional external enrichment must fail soft.
- Generated explorer foundation assets are deterministic build artifacts and remain gitignored, matching the existing world-map asset pattern.
- Stable country IDs use `ADM0_A3`; array position is never identity. Missing/placeholder or duplicate stable codes fail generation instead of silently inventing IDs.
- Natural Earth `Oceania` is normalized to classroom/display continent `Australia`, consistent with the established site; seven continent entities are always required.
- The compact entity/search index contains metadata, parentage, bbox/centroid and source provenance but no detailed geometry.
- Manual browser/input QA remains unverified until real evidence exists.
