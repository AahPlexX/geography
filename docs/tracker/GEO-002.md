# GEO-002 tracker — Interactive World Explorer

## Current state

GEO-002 is an approved architectural subproject for a new `/geography/explore/` experience. The authoritative design specification is `docs/superpowers/specs/2026-10-22-interactive-world-explorer-design.md`.

No production explorer code has been implemented yet. Existing GEO-001 routes and behavior remain the deployed baseline and are outside the implementation surface except for additive landing navigation and shared build/release wiring required to expose the explorer.

## Approved architecture

- Additive real page at `/geography/explore/`; preserve `/geography/`, `/geography/exam/`, and `/geography/map/`.
- Local-first static geographic data built from pinned/validated Natural Earth layers.
- Optional World Bank and Wikimedia enrichment only; no login, payment, API key, or secret required.
- Normalized geography model spanning continents, countries/territories, global Admin-1 subdivisions, marine/water features, rivers/lakes, landforms/physical regions, and populated places represented by canonical datasets.
- Progressive/lazy geographic layer loading; no all-world-detail startup payload.
- Touch, mouse, wheel/trackpad, and keyboard interaction parity.
- Search, hierarchy/breadcrumbs, related exploration, compare, distance measurement, local bookmarks, recent exploration, deep links, and adaptive entity details.
- Phone bottom-sheet, tablet adaptive split/sheet, and desktop persistent-panel patterns.
- WCAG 2.2 AA target, reduced-motion support, visible focus, non-gesture equivalents, and explicit manual input QA.

## External-source evidence verified 2026-10-22

- Natural Earth terms: raster/vector map data is public domain and may be modified/distributed without permission.
- World Bank Indicators API: API keys/authentication are not required.
- MediaWiki: anonymous cross-origin Action API requests can use `origin=*`; rate/request limits remain applicable.
- D3 zoom documentation: supports click-drag pan, wheel zoom, pinch/touch, programmatic transforms, and scale/translation constraints.

Exact source URLs and the associated architecture requirements are recorded in the GEO-002 specification.
